# Hospital Emergency Room Dashboard

## Project Summary

This project presents an interactive Hospital Emergency Room Dashboard developed using Microsoft Excel. The dashboard transforms emergency room data into meaningful visual insights and provides an overview of patient activity and hospital performance.

## Objective

The objective of this project is to analyze emergency room data and understand patient trends, waiting time, satisfaction, admission status, demographics, attendance, and department referrals.

## Tools Used

Microsoft Excel

## Skills Applied

Data Cleaning  
Data Analysis  
Data Visualization  
Dashboard Development  
KPI Analysis  
Pivot Tables  
Interactive Filters  
Charts and Reporting

## Key Metrics

Total Number of Patients  
Average Waiting Time  
Patient Satisfaction Score  
Patient Admission Status  
Patient Attendance  
Gender Distribution  
Age Group Distribution  
Department Referrals

## Dashboard Analysis

The dashboard provides an interactive view of patient trends and emergency room performance. Users can analyze the data using month and year filters and explore different patient and operational metrics.
